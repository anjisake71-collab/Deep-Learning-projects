# 🧠 Deep Learning Projects

Welcome to my **Deep Learning Projects** repository! This collection contains practical deep learning projects developed using **Python, TensorFlow, Keras, NumPy, Pandas, Matplotlib, and Scikit-learn**.

The projects cover **regression, binary classification, neural networks, model evaluation, underfitting, overfitting, regularization, dropout, early stopping, and L2 regularization**.

---

## 📁 Project Overview

### 1. California Housing Price Prediction

- **Objective:** Predict California housing prices using a deep neural network.
- **Techniques:** Artificial Neural Networks (ANNs), Regression, Model Validation, Regularization.
- **Libraries:** `TensorFlow`, `Keras`, `NumPy`, `Scikit-learn`, `Matplotlib`.
- **Highlights:** Explores model development from basic neural networks to underfitting, overfitting, Early Stopping, Dropout, and L2 regularization.

---

### 2. Employee Salary Prediction

- **Objective:** Predict annual salary based on years of experience.
- **Techniques:** Neural Network Regression, Feature Scaling, Model Evaluation.
- **Libraries:** `TensorFlow`, `Keras`, `NumPy`, `Pandas`, `Scikit-learn`, `Matplotlib`.
- **Highlights:** Includes step-by-step model development, salary prediction, and evaluation using MAE, RMSE, MAPE, and R².

---

### 3. Diabetes Classification Using Neural Networks

- **Objective:** Predict whether a patient has diabetes based on medical diagnostic features.
- **Techniques:** Binary Classification, Artificial Neural Networks, Dropout, Early Stopping, L2 Regularization.
- **Libraries:** `TensorFlow`, `Keras`, `Pandas`, `NumPy`, `Scikit-learn`, `Matplotlib`.
- **Highlights:** Compares different regularization approaches and evaluates classification performance using accuracy and confusion matrices.

---

### 4. Telco Customer Churn Prediction

- **Objective:** Predict whether a customer is likely to churn based on customer and service information.
- **Techniques:** Binary Classification, Neural Networks, Dropout, Early Stopping, L2 Regularization.
- **Libraries:** `TensorFlow`, `Keras`, `Pandas`, `NumPy`, `Scikit-learn`, `Matplotlib`.
- **Highlights:** Includes data preprocessing, feature encoding, stratified train-test splitting, and multiple regularization techniques.

---

### 5. Breast Cancer Classification

- **Objective:** Classify breast cancer cases using diagnostic features.
- **Techniques:** Artificial Neural Networks, Binary Classification, Feature Scaling, Model Evaluation.
- **Libraries:** `TensorFlow`, `Keras`, `NumPy`, `Pandas`, `Scikit-learn`, `Matplotlib`.
- **Highlights:** Uses a neural network for classification and evaluates the model using accuracy, precision, recall, F1-score, confusion matrix, and prediction probabilities.
